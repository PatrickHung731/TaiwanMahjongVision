# 開發階段規劃

**產品目標**：手機開著鏡頭對牌桌 → 螢幕即時顯示「打這張、放槍機率 X%」。
完全離線，裝進手機就能用。

要做到這件事需要三根支柱，缺一不可：

| 支柱 | 內容 | 狀態 |
| --- | --- | --- |
| 🧠 **算牌** | 打哪張最快聽牌、聽什麼、還剩幾張 | ✅ 完成 |
| 🛡️ **守備** | 打這張被胡的機率是多少 | ✅ 完成 |
| 👁️ **眼睛** | 鏡頭看懂自己的手牌 + 三家牌河 + 副露 | ⬜ 最大的工程 |

## Phase 2 — 鏡頭辨識 ⬜ 待開發（最大的工程）

### 2.0 先決定鏡頭怎麼擺 ⚠️

這件事會決定整個 App 的可用性，要先做決定：

| 擺法 | 看得到什麼 | 能給什麼建議 |
| --- | --- | --- |
| 手持、只照自己手牌 | 16~17 張手牌 | **只有效率**，放槍機率無法計算 |
| 架起來俯視整桌 | 手牌 + 四家牌河 + 副露 | 效率 + 放槍機率（完整功能） |

引擎兩種都支援（`TableState.opponents` 傳空 list 就是前者，
UI 會顯示「放槍機率：尚未辨識到牌河」而不是編一個假數字）。
建議做成**手機架 + 俯視角**，這也是實測辨識率最高的角度。

### 2.1 `FrameSampler` —— 1 FPS 抽樣
- CameraX `Preview` 維持 30 FPS 給使用者看，**不做任何推論**。
- `ImageAnalysis` 設 `STRATEGY_KEEP_ONLY_LATEST`，用時間戳閘門每 1000 ms 才真的推論一次。
- 推論跑在專用單執行緒；上一張還沒算完就直接丟棄新影格（不排隊，否則越積越慢）。

### 2.2 `YoloDetector` —— TFLite 推論
- 量化後的 YOLO-Nano（INT8 `.tflite`），放在 `app/src/main/assets/`。
- 前處理：`ImageProxy` YUV → RGB、letterbox 縮放、正規化。
- 後處理：解析輸出張量、信心度門檻、NMS。
- 委派：優先 NNAPI / GPU delegate，失敗退回 CPU（XNNPACK）。

### 2.3 `StateParser` —— 偵測框 → `TableState`
- 依 bounding box 位置分區：畫面下緣＝自己的手牌，中央＝牌河，四邊＝各家副露。
- 牌河要**保留順序**（先打的在前），因為筋牌判定跟打牌順序有關。
- 同一張牌連續 N 幀都出現才採信（時間投票），濾掉單幀誤判。
- 張數檢查：手牌必須是 16 或 17 張（扣掉副露），不符就顯示「請對準手牌」，
  **絕對不要硬算**——辨識錯一張牌，建議就整個歪掉。

### 2.4 模型訓練（真正的瓶頸）
- 類別數 34（或 42，把花牌也納入）。
- **資料集要自己拍**：台灣牌面（尤其條子與字牌字體）跟日麻公開資料集不一樣。
- 不同光線、角度、部分遮擋、立牌 vs 平放，每種至少數百張。
- 標註工具：Label Studio / Roboflow，輸出 YOLO 格式。
- 用 `ultralytics` 訓練並匯出 INT8 TFLite，實機量測單張推論時間（目標 < 300 ms）。

## Phase 3 — Android UI 與 AR 覆蓋層 ⬜ 待開發

- CameraX `PreviewView` + Jetpack Compose。
- 半透明 `Canvas` 覆蓋層：在偵測到的牌上畫框，建議打出的牌高亮、危險牌標紅。
- 底部資訊列直接用 `TableAdvice.overlayText()`：
  `建議切牌：9條 (放槍 1.8%) | 聽牌進張：3筒, 6筒 (剩餘 5 張)`
- 第二行用 `TableAdvice.alternativeText()`：`想收手：改打 東 (放槍 0.2%, 1向聽)`
- 進攻／平衡／防守三段切換（對應 `PlayStyle`）。
- 手動修正介面：辨識錯的時候可以點掉／補上一張牌（實戰一定會用到）。
- 狀態列顯示推論耗時與 FPS，確認沒有過熱降頻。
- 權限：只要 `CAMERA`；完全離線，Manifest 可以直接不要 `INTERNET`。

## Phase 4 — 台灣計台（可選）

胡牌後算台數：屏風、門清、自摸、碰碰胡、清一色、花台⋯⋯
`WinChecker.decompose()` 已經回傳拆解結果，可以直接接上去。
接上之後放槍風險就能從「機率」升級成「期望失點」（機率 × 台數）。

## 中途可交付的版本

不用等到辨識做完才有東西可以裝：

1. **手動輸入版 APK**：點選自己的手牌與看到的牌河 → 立刻給建議。
   幾天就能做出來，而且可以拿真實牌局驗證引擎準不準。
2. **半自動版**：鏡頭認自己的手牌（比較容易），牌河用手點。
3. **全自動版**：完整辨識整桌。
